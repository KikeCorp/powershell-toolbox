# PowerShell Toolbox

A collection of reusable PowerShell scripts, tools and technical notes.

This repository brings together practical scripts and utilities designed to simplify system administration, automate repetitive tasks and document useful technical operations.

## Contents

The repository is organized around the following topics:

- **Microsoft 365**: Administration and automation tools.
- **Exchange Online**: Mailbox management and reporting.
- **Microsoft Teams**: Administration and configuration utilities.
- **Windows Server**: System administration and maintenance.
- **Automation**: Reusable scripts and helper functions.

## Repository structure

```text
powershell-toolbox/

├── ExchangeOnline/
├── Teams/

├── Automation/
├── Documentation/
├── .gitignore
└── README.md
```
## Requirements
- PowerShell 7 or later where applicable.
- Required modules are documented in each script.
- Appropriate permissions for the operations performed.

## Usage

Each script includes documentation describing its purpose, requirements, parameters and usage examples.
Review scripts before running them and adapt them to your environment.
